# Cybersecurity Learning Journey – Junior Cybersecurity Analyst (HackTheBox)

Ovaj repozitorijum prati moj napredak kroz **Junior Cybersecurity Analyst** path na platformi [Hack The Box Academy](https://academy.hackthebox.com/). Cilj mi je da izgradim solidnu osnovu u informacionoj bezbednosti, mrezama, Linux/Windows sistemima i web bezbednosti, kao pripremu za dalju specijalizaciju (SOC analiticar / penetration tester).


## ✅ Do sada završeni moduli

### 1. Introduction to Information Security
Teorijski modul koji uvodi osnovne pojmove informacione bezbednosti – CIA trijada (Confidentiality, Integrity, Availability), vrste pretnji i napadača, osnovni bezbednosni koncepti i terminologija koja se koristi u industriji. Ovo je polazna tačka za razumevanje zašto i kako se štite informacioni sistemi.

### 2. Network Foundations
Modul koji objašnjava osnove računarskih mreža potrebne za rad u bezbednosti – OSI i TCP/IP model, IP adresiranje, mrežni uređaji i osnovni protokoli. Daje neophodnu podlogu za razumevanje kako podaci putuju kroz mrežu, što je preduslov za kasnije module o mrežnoj bezbednosti.

### 3. Introduction to Networking
Nastavak na mrežne osnove sa fokusom na praktičnije razumevanje mrežnih protokola, adresiranja i komunikacije između uređaja. Pomaže u izgradnji intuicije o tome kako funkcionišu mreže u realnom okruženju, uključujući osnovne alate za analizu saobraćaja.

### 4. Linux Fundamentals
Modul posvećen radu sa Linux operativnim sistemom i komandnom linijom (shell). Pokriva osnovne komande, navigaciju kroz fajl sistem, upravljanje fajlovima i dozvolama, procese, i osnovne administrativne zadatke. Linux je osnovni alat u cybersecurity poslu jer se većina alata za penetration testing i analizu pokreće na Linux distribucijama (npr. Kali Linux, Parrot OS).

### 5. Introduction to Bash Scripting
Modul koji uvodi osnove Bash skriptovanja za automatizaciju zadataka na Linux sistemima. Pokriva promenljive, uslove, petlje, funkcije i osnovnu obradu teksta (grep, awk, sed i sl.). Sposobnost pisanja Bash skripti omogućava automatizaciju ponavljajućih zadataka, što je ključna veština za svakog ko radi u tehničkoj ulozi u informacionoj bezbednosti.

### 6. Windows Fundamentals
Modul koji pokriva osnove rada sa Windows operativnim sistemom – arhitektura sistema, korisnički nalozi i dozvole, fajl sistem, registri i osnovni bezbednosni mehanizmi. Windows sistemi su i dalje dominantni u korporativnim okruženjima, pa je razumevanje njihove strukture neophodno i za ofanzivne i za defanzivne bezbednosne uloge.

### 7. Web Requests
Modul koji uvodi HTTP web zahteve i način na koji web aplikacije komuniciraju sa svojim backend sistemima. Obrađuje HTTP metode (GET, POST, itd.), strukturu zahteva i odgovora, kao i alate poput cURL-a i Browser DevTools-a za analizu i manipulaciju web saobraćajem. Ovo je prvi korak ka razumevanju web aplikacione bezbednosti i kasnijem web penetration testing-u.
